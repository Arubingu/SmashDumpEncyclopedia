# SmashDump Encyclopedia

[Open the Encyclopedia](https://arubingu.github.io/SmashDumpEncyclopedia/)

This repository contains the latest privacy-sanitized static export of the accepted SmashDump Encyclopedia. Historical builds are not published here.

- Encyclopedia: `0.1.14`
- Release date: `2026-09-25`

## Encyclopedia changes

- **Responsive interface** — Added the accepted phone and tablet layout with a category drawer, reliable return-to-results navigation, responsive summary controls and a collapsible category sidebar on desktop.
- **Compact browsing** — Made compact view the default for new visitors and repaired compact Stage / Quest presentation so its hierarchy and artwork remain intact.
- **Categories and navigation** — Separated Skills and Coup de Grâce into distinct category entries, reset category searches when navigating, and grouped ended Events, Shops and Gacha content into expandable sections.
- **Default ordering** — Refined Memory, Enemy, Event, Shop and Gacha ordering to follow their useful game-facing album, release and display order instead of generic alphabetical order.
- **Memory stat rankings** — Added rank badges beside S-rank base Memory stats, comparing each stat across the complete Memory catalogue with tied values sharing the same competition rank.
- **Changelog history** — Changed the changelog into a dated update archive: the latest update opens first while earlier updates remain available below it and are preserved across future releases.
- **Presentation polish** — Restored the accepted Mortamor Weapon identity and completed the Memory album-order and compact Stage presentation corrections found during community review.
- **Drony encyclopedia** — Added Drony as a full Encyclopedia category with all three units, level 1–60 sensor progression, upgrade effects and exact upgrade-material costs.
- **Expeditions and rewards** — Added expedition areas, unlock conditions, expedition items and expandable reward pools to Drony. Identical Normal and Great Success reward lists are presented once instead of duplicated.
- **Memory Effects / Pearls** — Added a Memory Effects category covering main-effect D/C/B/A/S progression, A/S secondary effects, rank assets and selectable legal secondary-effect pairings.
- **Pearl naming and presentation** — Replaced opaque numeric variants and technical conditions with player-facing weapon, element and family names, including weapon-specific elemental effects; normalized Defier naming and reused the correct main-effect art for matching secondary effects.
- **Status-effect decoding** — Resolved Weaken from the game data: it reduces Attack, Defence, Magical Might and Magical Defence by 20% for 5 seconds. Raw Status Type 18 presentation was replaced with the player-facing Weaken identity.
- **Combat presentation fixes** — Cleaned up remaining internal combat labels in affected abilities such as Anger and Darkwing Projectiles and restored readable player-facing status information.
- **Advanced Vocation restrictions** — Restored vocation-only labels on permanent Advanced Vocation Blessing upgrades so restricted effects clearly identify the vocation they apply to.
- **Images and browser compatibility** — Corrected missing or inverted Drony, expedition, rank and Memory Effect imagery and fixed the vocation-tree image clipping issue on Firefox / Gecko browsers.
- **Stability and responsive polish** — Fixed crashes when opening Weaken and Memory Effect secondary details, improved Drony cards at narrow widths, and kept the new categories consistent with the accepted desktop, mobile and compact layouts.
