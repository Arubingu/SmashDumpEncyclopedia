## Encyclopedia changes

- **Cleaner filters** — Cleaned up Memory filters by removing the redundant Description filter, ordering passive families by the game's source order, and adding Select all / Clear controls wherever a filter has multiple choices.
- **Skill tags at a glance** — Skill cards now show their player-facing tags directly in the list, making traits such as Arrow, Sphere and weapon-granted skills visible without opening the filter panel.
- **Vocation progression and Boons** — Expanded vocation pages with a proper level curve, EXP to the next level, per-level stat gains and Level-up Boons, including permanent Hero-wide bonuses that remain active after changing vocation.
- **Memory comparison** — Added a full Memory comparison mode that places two database-derived Memory pages side by side, keeps rank/stat information intact, and removes navigation links that do not belong inside the comparison view.
- **Smoother comparison workflow** — Refined Memory comparison selection so browsing never changes card sizes or loses your scroll position. Selected Memories are highlighted directly on their cards, the first pick stays visible in the comparison header, and closing the comparison clears the temporary selection.
